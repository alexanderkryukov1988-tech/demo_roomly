# Отчёт по тестовому заданию

Стенд: https://rcsi-science.github.io/demo-roomly/

## Окружение

- Windows 10 Pro 22H2, сборка 19045
- Python 3.15.2, pytest 8.3.5, Playwright 1.64.1
- Chromium 156.0.8078.4, headless
- Docker: образ mcr.microsoft.com/playwright/python:v1.64.1-noble, прогон через docker compose подтверждён

## Запуск

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe -m pytest
```

Через Docker: `docker compose run --build --rm tests`. Результаты в `artifacts/`, скриншоты дефектов в `artifacts/evidence/`.

## Проверенные области

- обязательные поля и предупреждения по каждому из них;
- дата: прошедший день, ограничение календаря, сегодняшний день;
- время: порядок начала и окончания, длительность и её границы;
- участники: от 1 до 20 и вместимость выбранной комнаты;
- имя и почта: обязательность, формат, спецсимволы;
- сообщение об успехе и его содержимое;
- отсутствие сохранения данных после перезагрузки;
- клавиатурная навигация, ошибки в консоли, вёрстка на 375 px.

Итог прогона: 31 passed, 5 failed (найденные дефекты), 1 xfailed; чек-лист 28 Pass, 5 Fail из 33.

Результат: [checklist.md](checklist.md), [bugs.md](bugs.md).

## Ограничения

- Проверено только в Chromium, в Firefox и WebKit тесты не запускались.
- Тест CL-13 с текущим днём не запускать с 00:00 до 03:00, поскольку результат зависит от локального времени.

## Вопросы и допущения

- Тексты предупреждений в требованиях не заданы, проверялся смысл, а не формулировка.

## Время

Около 2 часов 20 минут на разбор задания, ручную проверку формы, 33 теста по чек-листу, 3 теста задания, 5 багрепортов и отчёты.

## Использование ИИ

Большую часть кода и текстов подготовил ИИ, я задавал направление и принимал результат.

Моё:

- архитектура фреймворка: JSON-локаторы, page object, слой тестовых данных, маркеры `positive`/`negative`;
- постановка задач, структура чек-листа и отчётов, приоритеты дефектов;
- формулировки и формат багрепортов, состав чек-листа, отказ от лишних решений;
- запуск прогонов и решения что считать дефектом, а что ошибкой теста;
- скриншоты к дефектам.

ИИ:

- код page object, тестов и скриптов отчётов;
- черновики чек-листа и багрепортов.
